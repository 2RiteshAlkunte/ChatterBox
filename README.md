# ChatterBox

ChatterBox is a real-time chat application with web and mobile versions.

## Tech Stack

- React
- React Native
- Node.js
- Express
- Socket.io
- MongoDB
- Expo

## Project Structure

```text
ChatterBox/
├── backend/
├── frontend/
└── mobile/
Running the Project
Backend

Open a terminal:

cd backend
npm install
npm run dev
Frontend

Open another terminal:

cd frontend
npm install
npm start

The web application will open in the browser.

Mobile App

Open another terminal:

cd mobile
npm install
npx expo start

Scan the QR code using the Expo Go app on an Android device.

The mobile app and web application use the same backend, so messages can be exchanged between devices in real time.

Features
User registration and login
Guest mode
Chat rooms
Real-time messaging
Typing indicators
Online users
Room search
Responsive web interface
React Native mobile application
